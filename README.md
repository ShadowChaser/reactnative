# Little Lemon React Native Capstone

A small Expo app built around the Little Lemon capstone brief. It includes a first-run onboarding form, a searchable and filterable menu, an editable profile, device persistence, log out, and a back action for returning to the previous screen.

## Run locally

1. Install Node.js 20.19 or newer.
2. Run `npm install` in this folder.
3. Run `npm start` and open the project with Expo Go, or use `npm run android`, `npm run ios`, or `npm run web`.

The profile is stored with AsyncStorage on the device. Use **Log out** to remove the saved profile and return to onboarding.
